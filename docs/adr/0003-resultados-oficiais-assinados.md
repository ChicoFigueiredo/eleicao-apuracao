# Resultados oficiais assinados antes da persistência

O coletor consumirá os arquivos de divulgação oficiais do TSE e só gravará uma Leitura Histórica depois de validar a assinatura JWS. A alternativa de confiar apenas no HTTPS ou raspar a interface pública não oferece a mesma cadeia verificável de integridade para os números preservados e exibidos pelo Monitor Eleitoral.
